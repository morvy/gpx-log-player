GPX log validator

GPX log player · Statistics

Open or drop a GPX file to check it.

It is checked against the schema and the player's own requirements, in this browser - nothing is uploaded.

What a file needs

  • GPX 1.1, valid against the schema: the GPX 1.1 schema, Garmin's TrackPointExtension v2 and the ev extension for what the vehicle logged.
  • At least two track points, each with lat, lon and a time, in time order. GPX itself lets time out; the player cannot play a track without it.
  • Every value in the ev namespace is a number, and ev:cells_v has the same count on every point. The schema checks the names below; any other name it lets through, so this page checks those.

Everything else is optional and adds to what the player shows: ele for altitude and climb, gpxtpx:speed (m/s) for speed, gpxtpx:course for heading, and these values on each point's <extensions>:
